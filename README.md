# Pelican on a Bicycle

A single-file interactive WebGL postcard: a pelican, a vintage bicycle, and one golden hour on a coastal pier.

**Live:** https://kanemaverick.github.io/pelican-on-a-bicycle/

## What's inside

- Procedural Three.js character and bicycle (no external models)
- Custom sky, ocean, and film-grade shaders
- Animated pedalling, wing/leg IK, scarf, chain, waves, clouds, birds, and dust
- Orbit camera, cinematic intro, four camera presets
- Golden hour / blue dusk / moonlight lighting states
- Web Audio ocean, wind, pad, seagulls, bell, and a comic honk
- Snapshot postcard export, share link, photo mode, keyboard shortcuts
- Responsive layout for desktop, tablet, and mobile

Built as a single self-contained `index.html` with Three.js bundled inline. Hosted on GitHub Pages (Fastly CDN).
